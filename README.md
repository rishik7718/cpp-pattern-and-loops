## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/cpp-pattern-generator.git
```

### 2. Open the Project

Open the repository in Visual Studio Code.

### 3. Compile Any Pattern

```bash
g++ StarPattern.cpp -o pattern
```

### 4. Run the Program

```bash
./pattern
```

(Windows users can run `pattern.exe`.)
